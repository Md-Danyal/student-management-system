# Student Management System (Python)

A **console-based Student Management System** built using **Object-Oriented Programming (OOP)** principles in Python.  
This project focuses on clean code structure, abstraction, and modular design.

---

## 📌 Project Overview

The Student Management System allows users to manage student records through a menu-driven interface.  
It demonstrates **real-world OOP design** by separating responsibilities across multiple modules.

---

## ✨ Features

- Add new students  
- View all students  
- Search students by ID  
- Update student details  
- Delete student records  
- Menu-driven command-line interface  

---

## 🧠 OOP Concepts Used

- **Abstraction**
  - Implemented using Python’s `abc` module
  - Abstract base class defines required behavior
- **Composition**
  - `StudentManagement` manages multiple `Student` objects
- **Modular Design**
  - Each responsibility is separated into its own file
